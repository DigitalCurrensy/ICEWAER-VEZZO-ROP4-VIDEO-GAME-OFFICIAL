## One sentence

Drive the white sedan six miles through night traffic, stack score, post your rank.

One run is about a minute. Free. No account.

## Title menu

| Button | Does |
|---|---|
| PLAY | Start a run |
| GARAGE | Car / loadout view |
| HOW TO PLAY | In-game controls |
| LEADERBOARD | Rank board on the live build |
| SOUND ON / OFF | Mute |

Title tagline: *Six miles. One city. Run your rank up.*

## During a run

1. Steer the white ROP 4 sedan.
2. Collect Purple Pints and cash.
3. Thread traffic for Perfect Dodges.
4. Tap BOOST on an open lane.
5. Finish six miles and share the rank card with `#ROP4`.

### HUD

| Item | Meaning |
|---|---|
| MILE | Distance through the run |
| REMAINING | Miles left |
| PINTS | Purple Pints this run |
| CASH | Cash picked up |
| Score | Live score |
| SHIELD | Hits left |
| BOOST | Speed surge ready |

Phone uses on-screen controls. Desktop uses the keys printed on the start screen.

## If it does not load

Open https://blue-cloud-787.higgsfield.gg/ directly. If an embed is blocked, use the new-tab / fullscreen button on https://richoffpints.com/.
