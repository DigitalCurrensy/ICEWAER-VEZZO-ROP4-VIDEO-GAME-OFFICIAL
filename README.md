## What this is

ROP 4 is Icewear Vezzo's album campaign **and** a luxury night traffic racer.

You are not downloading an app. You open the game in a browser, hit **Play**, and drive.

| City | Detroit night — wet asphalt, neon storefronts, purple storm light |
| Goal | Stack score across 6 miles. Collect pints. Dodge traffic. Share the rank card. |
| Cost | Free |
| Account | None |

## How to play

Full guide: [docs/HOW_TO_PLAY.md](docs/HOW_TO_PLAY.md)

**The 60-second loop**

1. Open the game. Hit **PLAY**.
2. Steer the white sedan. Keyboard or touch — stay in lane, cut when you have a gap.
3. Grab **Purple Pints** (glowing cups) and cash on the road.
4. Miss traffic by inches for a **Perfect Dodge**.
5. Tap **BOOST** when you have a clear lane.
6. Survive the six miles. Share the rank card with `#ROP4`.

You do not need an account. If the embed on richoffpints.com is blocked, use the fullscreen game link above.

## What this repo is — and is not

This GitHub repo is the **official public record** of the ROP 4 game:

- What the game is
- How to play it
- Screenshots and media
- Honest notes on where the live build lives
- How scores / ranks work today ([docs/DATA.md](docs/DATA.md))

This repo does **not** contain:

- The Higgsfield engine source
- Soundtrack masters
- A standalone leaderboard database you can run locally
- App-store binaries

The playable game is the Higgsfield build linked above. The campaign website that embeds it lives in [ICEWEAR-VEZZO-ROP4-WEBSITE](https://github.com/DigitalCurrensy/ICEWEAR-VEZZO-ROP4-WEBSITE).

> Repo folder name note: GitHub lists this repository as `ICEWAER-VEZZO-ROP4-VIDEO-GAME-OFFICIAL`. That is a historical typo in the URL. The official spelling is **Icewear**.
