## What this is

ROP 4 is Icewear Vezzo's album campaign **and** a luxury night traffic racer.

You are not downloading an app. You open the game in a browser, hit **Play**, and drive.

| | |
| --- | --- |
| Title | ICEWEAR VEZZO — ROP 4 — 6 Mile Night Run |
| Loop | ~60 seconds per run |
| Vehicle | White ROP 4 luxury sedan |
| City | Detroit night |
| Goal | Stack score across 6 miles. Share the rank card. |
| Cost | Free |
| Account | None |

Presented by **Iced Up Records**. Campaign site by **Digital Currensy Inc.** Playable build hosted on **Higgsfield**.

## How to play

Full guide: [docs/HOW_TO_PLAY.md](docs/HOW_TO_PLAY.md)

1. Open the game. Hit **PLAY**.
2. Steer the white sedan.
3. Grab **Purple Pints** and cash.
4. Hit **Perfect Dodges**.
5. Tap **BOOST** on an open lane.
6. Share the rank card with `#ROP4`.
